# IxDL Studio Demo

这是一个用 SwiftUI 编写的 iPhone / iPad 交互原型，用于展示项目列表、原型体验、链接与二维码分享，以及设置页面。项目可以直接在 Xcode 中运行；没有第三方依赖。

## 运行

1. 用 Xcode 打开 `SettingsDemo.xcodeproj`，选择 `SettingsDemo` scheme。
2. 选择 iPhone、iPad 模拟器或真机，然后运行。
3. 使用演示账号 `Joker`、密码 `123456` 登录。

最低系统版本为 iOS / iPadOS 16。拍摄照片和实时扫描二维码需要支持相应功能的设备；无法实时扫描时，页面会提供手动粘贴链接的入口。保存分享卡片需要照片添加权限。

## 主要交互

- **项目列表**：初始有两个示例项目，使用资源目录中的默认封面。相机拍摄的照片会作为新项目的预览图。
- **自适应布局**：紧凑宽度使用单栏列表；常规宽度使用侧边栏和详情区。iPad 顶部导航图标使用更紧凑的间距。
- **原型体验**：打开项目后进入全屏演示页。摇晃设备或四指触屏可以打开操作菜单；触发方式可在设置中调整。
- **分享**：可生成带有效期参数的链接及二维码。链接页提供复制和系统分享；二维码页可以将包含品牌标识、二维码和说明文字的完整分享卡片保存为 PNG 到照片。
- **设置**：包含账号信息、退出手势、中英文界面切换、版本及第三方协议说明。

## Demo 范围

这是用于界面和交互验证的 demo。账号与密码写在本地代码中，不具备正式身份认证能力。项目列表和新拍摄的预览图只保存在当前运行内存中，重新启动后会恢复为示例数据；登录状态和语言选择使用 `UserDefaults` 保存。

分享链接中的 `share.ixdl.studio` 目前没有对应的项目托管服务。App 可以解析传入的链接、识别二维码内容并检查链接中的过期时间，但跨设备分享完整项目内容需要后端和正式的链接接入配置。全屏“原型体验”页目前也是占位演示内容。

## 代码位置

| 路径 | 内容 |
| --- | --- |
| `SettingsDemo/ContentView.swift` | 登录、项目模型、首页、自适应布局、相机入口和项目详情 |
| `SettingsDemo/PlaceholderViews.swift` | 链接分享、二维码卡片、扫描和原型演示 |
| `SettingsDemo/SettingsView.swift` | 设置页面 |
| `SettingsDemo/Assets.xcassets` | 品牌图、封面和导航图标等资源 |

相机和照片写入权限说明位于 `SettingsDemo/Info.plist`，中英文文案分别位于对应的 `InfoPlist.strings` 文件。
